# Le Royaume des Cendres

Prototype jouable de dark fantasy en vue de dessus, conçu pour être hébergé sur GitHub Pages.

## Lancer le jeu
1. Téléchargez `index.html`.
2. Ouvrez-le dans un navigateur récent (connexion Internet nécessaire pour rien : le prototype n'utilise aucune bibliothèque externe).
3. Pour publier : créez un dépôt GitHub, ajoutez `index.html` et `README.md`, puis activez **Settings → Pages → Deploy from a branch → main / root**.

## Commandes
- **ZQSD / WASD** ou flèches : déplacement
- **E** : parler / examiner / continuer un dialogue
- **Espace** : attaquer
- **Maj** : esquive

## Contenu du prototype
Carte explorable, chevalier, squelettes, troll, PNJ, dialogue, quête, points de vie, éclats à récupérer, brouillard, vignette sombre et rendu volontairement adouci.

## Suite possible
Sprites animés, vrai modèle 3D, inventaire, sauvegarde, plusieurs régions, boss dragon, quêtes à embranchements et sons.
